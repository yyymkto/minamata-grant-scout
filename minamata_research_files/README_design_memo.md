# 水俣市 補助金マッチング 地域プロファイル設計メモ

作成日：2026年9月11日　／　対象ファイル：`minamata_profile.yaml`、`scoring_reference.py`

## 1. このメモの目的

これまでの調査（項目1〜8）で得た統計・政策情報を、補助金マッチングシステムの配点根拠として実装できる形に整理したものです。数値はすべて `minamata_profile.yaml` に出典・時点・確度とともに格納し、配点ロジックは `scoring_reference.py` で再現できるようにしています。本メモは、その設計判断の理由と、今後の更新方法を説明します。

## 2. 調査結果の要点

水俣市の最大産業は医療・福祉です。2020年国勢調査で就業者の24.8%（2,563人）を占め、全国比で約1.8倍の集中度があります。2018年の地域経済循環分析でも付加価値1位で、域外からの所得獲得産業にも含まれます。雇用・経済規模・政策の三つの指標が一致する唯一の分野であり、最重点とする根拠は十分です。

製造業は就業者15.2%で2位ですが、化学（JNC関連）と木材・木製品の2業種で製造業付加価値の約7割を生む、資本集約的な構造です。総合計画の「外貨を稼ぐ水俣」の中核でもあり、経済規模と政策の両面から2番手に置きます。

観光・スポーツは就業者4.3%と小さいものの、総合計画の最重要プロジェクト「活力生まれる水俣」の柱です。統計上の重みと政策上の重みが大きく食い違う分野であるため、配点では両者を別の軸（産業適合とテーマ適合）で扱います。

林業は就業規模が小さく独立した重点産業とする根拠は弱い一方、森林が市域の約74%、木材・木製品製造業が製造業付加価値の約36%を占めます。「森林・林業・木材利用」という横断項目として保持します。

移住・定住は制度が一通り揃っていますが、総合戦略のKPIは「移住支援策を活用した転入者数を4年間で120人」と控えめで、優先度は中程度と評価しました。関係人口づくりでは、水俣病の学びを組み込んだ企業研修型ワーケーションに独自性があります。

「もやい直し」は現在も施設（もやい直しセンター）、行事（慰霊式、火のまつり）、県補助事業として継続しています。ただし市の看板政策としての比重は1990年代より下がっています。単独ジャンルではなく、水俣固有性の加点タグとして扱います。

## 3. 配点モデル

最終スコア（0〜100）は、次の4要素の合計です。

| 要素 | 重み・上限 | 内容 |
|---|---|---|
| 産業適合 | 0.45 | 補助金が対象とする産業の地域重点度（下記の式） |
| テーマ適合 | 0.35 | 補助金の政策テーマと市の優先度の一致度（Pを0〜100に換算） |
| 固有性加点 | 最大15点 | 水俣病発生地域限定制度、もやい直し、地域振興計画など |
| 時限加点 | 最大10点 | 令和8年熊本地震の復旧、水俣病公式確認70年事業など。期限で自動失効 |

産業の地域重点度は `(0.4×E + 0.3×V + 0.3×P) × 20` で算出します。Eは就業者シェア指数（医療・福祉の24.8%を5とする相対値）、Vは付加価値指数、Pは政策優先指数で、いずれも0〜5です。現在の値は次のとおりです。

| 産業 | E | V | P | 重点度 |
|---|---|---|---|---|
| 医療・福祉 | 5.0 | 5.0 | 4.0 | 94 |
| 製造業 | 3.1 | 4.0 | 5.0 | 79 |
| 卸売・小売・商店街 | 2.8 | 2.0（仮） | 3.0 | 52 |
| 建設業 | 1.5 | 4.0 | 2.0 | 48 |
| 観光・宿泊・飲食・スポーツ | 0.9 | 1.5 | 5.0 | 46 |
| 農業 | 1.1 | 1.0 | 3.0 | 33 |
| 森林・林業・木材利用 | 0.3 | 2.5 | 2.5 | 32 |
| 水産業 | 0.1 | 0.5 | 2.5 | 19 |

重み（0.4／0.3／0.3、0.45／0.35）は調査結果から導いた試案であり、統計的に推定したものではありません。実装後、過去の採択実績や市担当者の評価と照らして校正することを前提としています。

## 4. 固有性タグと運用ルール

固有性加点は、補助金の対象要件や事業内容が条件を満たす場合にのみ付けます。最も強いのは `MINAMATA_DISEASE_AREA`（15点）で、対象地域や対象者が水俣病発生地域・被害者に限定される制度（胎児性・小児性患者等の地域生活支援事業、環境・福祉モデル地域づくり推進事業など）が該当します。`MOYAI`（10点）は、コミュニティ修復、慰霊、教訓継承、被害者福祉、学び型交流を内容に含む事業に付けます。

過疎地域の指定や産業振興促進区域（製造業、情報サービス業等、農林水産物等販売業、旅館業）は、他の過疎自治体にも共通する制度のため、加点ではなく「対象になれるか」の判定フラグとして扱います。

運用上、次の点を必ず守ります。

- `MOYAI` タグは移住支援金、住宅取得補助、空き家バンクなどの汎用移住施策には付けません。水俣病を移住プロモーションに利用していると受け取られるリスクがあるためで、リファレンス実装でも自動的に抑止しています。
- 経済規模の指標からは、住宅賃貸業（持ち家の帰属家賃）と公務を除外します。
- 水俣市は環境モデル都市とSDGs未来都市に選定されていますが、環境未来都市ではありません。
- 人口は住民基本台帳と国勢調査で定義が異なるため、表示時に定義を明記します。

## 5. 既知の弱点

リファレンス実装を動かすと、次の傾向が確認できます。いずれも実装時の校正候補です。

- テーマのみで産業分類を持たない補助金（例：移住支援金）は、産業適合の重みがテーマ側に寄るため、やや高めに出ます。テーマのみの場合に係数を割り引くかどうかは要検討です。
- 卸売・小売のV（付加価値指数）は、上位3位圏外という情報しかないため仮置きです。
- P（政策優先指数）は計画文書の記述から設定しており、解釈を含みます。第7次総合計画の策定時に全面的に見直す前提です。
- 経済規模データは2018年時点です。熊本県が2026年3月に公表した令和5年度市町村民経済計算で早急に更新すべきです。

|---|---|
| 即時 | 2025国勢調査の水俣市速報人口、県の令和5年度市町村民経済計算を取り込む |

| 毎年3月頃 | 市町村民経済計算の新年度分でVを更新 |
| 2027年3月頃（想定） | 第7次総合計画の議決を受け、全産業・全テーマのPを見直し |
| 2027年頃（見込み） | 2025国勢調査の産業別就業者が公表されたらEを再計算 |
| 各期限日 | 時限加点を自動失効（70年事業：2027年3月末、地震：2028年3月末を仮置き） |
